# Inspect existing suffix traces before collecting more terminal supervision

The conditional readout fits 98.49% of its 332 training terminal pairs but does not transfer. Its active feature matrix has full row rank, while consequential contexts are sparsely represented. This supports investigating data quality and coverage before another fit; it does not establish either as the cause.

Use the admitted 1,000-game, 3,000-branch continuation panel and its already audited action traces. The traces contain full-input hashes, full-runner state fingerprints and global card-UID counters, selected actions, deterministic base modes, compact after-state metrics and terminal outcomes. They do not contain full observation tensors. Inventorying their reuse therefore precedes any costly replay or proposed training data expansion.

Count all and followup-only events, unique input hashes, unique observed state–action pairs, repeated pairs, distinct source games, phase distribution and source-game split overlap. Distinguish forced initial actions from base-policy followups. Count exact full-observation-and-action matches with differing terminal labels. Such matches would establish conflicting realized targets for that observed input under this controller, without identifying which omitted state or future randomness caused the difference. No matches would not establish deterministic or reliable labels. Verify identical observation hashes yield the same recorded greedy mode; verify matching full-state fingerprint, global UID counter and action agree on next state/UID and terminal outcome. Any disagreement in these deterministic checks stops admission.
