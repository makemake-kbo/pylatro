# Locate consequence-head errors within fixed-base overrides

The completed fixed-base experiment recovers most lost clears but still makes 74 clear-losing and 62 clear-gaining overrides relative to base. Before selecting another architecture or objective, inspect its admitted full-support predictions and realized outcomes. Does the clear head rank the successful action correctly while preference selects the other action, or do both heads rank it incorrectly? This distinguishes observed disagreement between outputs from an incorrect consequence ordering; it does not identify a unique causal bottleneck.

Use only the completed endpoint's saved predictions, action records, retention audit and choice-accounting result. Cover all 847 overrides, partitioned into 248 newly leaving base, 335 unchanged previous overrides and 264 changed overrides. Reproduce those counts and all realized gains/losses. For clear-discordant choices, compare the score and clear outputs for the selected and base actions against which one actually cleared. Report strict correct, wrong and tied ordering and their joint categories. Keep clear-losing and clear-gaining comparisons separate. Do not select a replacement action or evaluate a new policy.

For each override save the two actions, known outcomes, predicted score/clear/preference values and the fixed-base versus learned-correction preference margins. Verify action identities, chosen predictions and centered-preference composition against admitted artifacts. This is post-hoc descriptive analysis with no new inference, simulator labels, bootstrap, optimization, threshold tuning or scientific gate. Original-RNG labels remain realized outcomes rather than conditional means. A correct consequence ordering does not establish that maximizing immediate clears would improve eventual wins; an incorrect ordering does not establish that independent features are necessary.

Use standard-library parsing with a 600-second cap plus 30 seconds of process supervision. No final-confirmation data are read.
