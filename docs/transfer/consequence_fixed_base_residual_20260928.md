# Test a consequence correction around an immutable base policy

**Question.** Does rebuilding all play preferences in a separate scorer discard useful information in the existing action distribution? The strongest competing explanation is that the learned corrections themselves transfer poorly, so a fixed base would merely retain existing errors. The [survival-ranking result](consequence_survival_ranking_results_20260928.md) supports both concerns: it improves held-out pair error but loses 162 clears versus base, and 1,226 choices change outside the last-hand population where the new loss applies. This is a specific output-parameterization hypothesis, not evidence that frozen features or context length are inadequate.

The current consequence scorer chooses the largest standalone preference logit. The existing policy instead normalizes an internal reference distribution plus subset energies (`action_grammar.py`, `_corrected_hand_log_probs`). Earlier full-policy ranking and KL-preservation fits changed that internal reference and shared encoder features; [their score decomposition](ranking_preservation_score_decomposition_20260927.md) explicitly distinguishes it from a frozen base. A frozen KL reference constrained a trainable policy through a penalty. This experiment would place the complete frozen base play distribution directly in the new scorer's output and retain the frozen feature path. It is not another KL coefficient experiment or a claim that residual heads are new to this repository.

**Controlled intervention.** Keep the latest survival-ranking readout, seed-0 weights, 292,762 labels, 3,396 survival pairs, 47,149 states, frozen features, full legal support, state order and all four loss terms. Replace only the preference used by teacher CE, survival ranking and action selection:

`preference(state, action) = log P_base(action | play, state) + R_theta(state, action) - R_initial(state, action)`.

`R_initial` is an immutable copy of the same initial readout's preference function. Subtracting it preserves identical trainable initialization and gives an exactly zero correction at initialization when both readouts use the same inputs and computation. The base conditional includes its already learned subset energies, candidate/AR mixture and complete legal support. It is not the internal pre-energy reference or a hard one-hot base action. The coefficient on the fixed log probability is one, with no sweep. Score and clear outputs remain the current readout's outputs. The extra initial readout is frozen, not a second trained replica or an independently trainable feature branch. Base non-play choices remain preserved by the existing rule.

Neither fixed function receives outcomes, seeds, future draws or hidden RNG. Base log probabilities are computed from the original visible observation only, cached for fitting, and detached. The learned readout continues to receive only the existing visible feature keys. The frozen initial readout remains fixed even when shared layers in the trainable readout change. Keep all existing state/action ordering, masking and original-RNG target limitations.

**Cheapest prerequisite.** Before caching or fitting, reproduce the fixed base on the first 96 original training teacher-play rows, in three batches of 32. Check every legal conditional log probability for finite values and normalization; match the complete mode and teacher NLL against the archived base predictions; reconcile the teacher conditional with the public joint log-probability API and play-family probability; match legal support and cache identities to the admitted training support. On every legal action in this probe, verify that `R_theta − R_initial` is exactly zero and the resulting eligible choice equals base. Check unchanged tensors and no gradients. Save the raw values for a separate numeric recount. This probe tests the correctness and cost of the proposed fixed output, not generalization.

**Prediction and decision.** If the standalone readout's missing base distribution is consequential, the residual fit should recover retained clears and early clears while preserving useful corrections. A collapse to base without improvement, or failure of the same complete-action retention gates, rejects advancement. Keep all four prediction gates, all four retention gates and the existing fixed epoch-20 endpoint. Evaluate every selected action, fixed control-action predictions and survival-pair transfer. Use the completed survival-ranking fit as the matched readout control and base as the retention reference. No new teacher-agreement gate, confidence threshold, hard last-hand routing, loss coefficient or duration choice is introduced.

**Budget.** Reuse all existing labels, features, support and order. The original feature cache took about 1,131 seconds for training and 143 for development; its first full-policy batch took about 0.82 seconds. These are historical estimates, not a measured cost for the new cache. Bound the 96-state probe and saved-value audit at 600 seconds each plus 30 seconds supervision grace. Use its measured base-forward timings to project a complete fixed-prior cache; require three times the projection to fit the existing 7,200-second training / 1,800-second development cache caps before proceeding. A later backward-only preflight must measure the extra frozen-readout cost and verify the changed loss math before admitting one fixed-20 fit. Reuse 7,380 updates, 942,980 state presentations, CPU FP32, one thread and the latest optimizer recipe for a controlled comparison; freeze its measured time budget before training. No fit is admitted by this note alone.

Only a candidate passing the unchanged prediction and retention screens advances to policy integration and fresh sampled/greedy/early-attribution evaluation. The full goal still needs the original win-rate improvement standard and a final independent confirmation fit. World models remain deferred. If this fails, report whether base retention improved at the expense of corrections before choosing another mechanism; do not automatically sweep preservation strength.
