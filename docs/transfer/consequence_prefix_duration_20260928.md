# Earlier consequence-readout checkpoints: a separate duration evaluation

The fixed epoch-20 [readout experiment](consequence_readout_results_20260928.md) failed retention for both heads. The [support diagnosis](consequence_support_results_20260928.md) localizes its regressions, while the already measured prefix curves show an earlier development preference peak. This new evaluation checks that cheaper intervention before any additional fit. It is post-hoc development work, not fresh confirmation, and does not replace the original failed endpoints.

Select the saved epoch with the smallest development original-proposal teacher-preference NLL among epochs 0, 5, 10 and 20, breaking ties toward the earlier epoch. Existing audited curves select **pooled epoch 5** and **relational epoch 10**. Freeze those selections, checkpoint hashes, prior prediction arrays and all helpers before new full-action choices are measured. No new training or optimizer step is allowed.

For each selected checkpoint, reconstruct the same 128 factual development games and all 26,045 observations/teacher decisions. At every teacher-play state, score all legal plays using the shared frozen feature cache and the selected saved head. Preserve the base's non-play action; otherwise take preference argmax with lowest-action-ID tie breaking. Save the complete support and three output coordinates. Require overlapping original-proposal values to match the admitted prefix prediction array within rtol/atol 1e-5, and require unchanged head tensors/no gradients.

Every chosen action needs an actual recorded-continuation outcome. Reuse the shared proposal labels first, then the admitted pooled/relational epoch-20 selected-action outcomes where the state and action are identical. Check every duplicate outcome for equality. Simulate all remaining choices through the full action transition, maintaining factual observation/teacher-outcome parity, original RNG continuation, legal masks, parent isolation, card counters and original game terminals. No RNG stress draw, hidden-state feature or autonomous policy rollout is introduced.

An independent saved-data auditor reconstructs legal support and argmax, checks all row identities and reused outcomes, and recounts outcomes. It recomputes the selected prefix's original-proposal losses from its admitted prediction array, matches the prior audited means, and calculates the same four prediction gates against training-only constant/count-by-Ante baselines. Use the existing tested state-balanced metrics and 10,000 shared whole-game bootstrap draws (Python Random seed 1729, ratio of summed per-state differences to sampled counts, linear percentiles). Report prediction strata all/early/later/other, retention all/early/later/base-match/base-disagreement, and paired retention differences versus base and the same readout's epoch-20 choices. These are descriptive development intervals, not training-replica uncertainty or win-rate intervals.

Retention keeps the existing four gates: strictly more overall clears than base, at least as many early clears, and no increase in either total immediate losses or newly introduced losses where the teacher survives. Both prediction and retention must pass before a prefix can advance. If both pass, use the declared rule: more overall clears, then more early clears, fewer total losses, lower standardized score MSE plus clear BCE, then pooled on an exact tie. Any later policy integration/fresh-game evaluation requires its own fixed protocol and the original long-horizon/confirmation bar. This evaluation itself performs neither.

Run pooled measurement/audit then relational measurement/audit, serially. Bound each combined full-support/factual-replay measurement to 1,800 seconds and each independent audit to 1,200, with 30 seconds of supervision grace. Preserve failures; no automatic retries or extensions. Admit results only after the actual owner exit and all four successful phase exits. If neither prefix passes, close this duration intervention and use the measured support gap to design one controlled full-legal-support preference-loss experiment.
