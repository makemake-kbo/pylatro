# Saved-data diagnosis of consequence-readout retention failures

This is a post-hoc diagnosis of the [completed readout experiment](consequence_readout_results_20260928.md), whose two fixed endpoints failed retention. It does not change those gates, qualify a policy, choose a new endpoint, or use fresh games. No fitting, neural inference or simulator calls are needed: every selected action already has an audited outcome.

Bind the actual completed comparison owner and both arms' prediction/retention audits, full legal-action values, choices and shared development labels. Reconstruct all row identities and full-support argmax choices, and reproduce the existing proposal prediction means and retention counts before reporting new statistics. Preserve failures and observe the diagnostic owner's actual exit.

For the 6,008 eligible base-play states, report the following separately for both readouts:

- Full-support versus original-proposal preference argmax, teacher agreement/rank and teacher NLL. Report selected actions inside and outside the original proposal set, early/later states, and base/teacher agreement strata.
- Clear/loss counts and gained/lost clear sets for the base, original-proposal argmax and full-support argmax. The restricted set includes the teacher by construction; this is an oracle-assisted diagnostic, not a deployable policy or an advancement candidate.
- State-balanced log-score MSE, clear BCE/Brier score, predicted clear probability and realized clear rate for chosen actions. Compare selected-action errors with the per-state mean error on original proposals at the same states. Differences describe the selected distributions; they do not isolate a causal architecture effect.
- Every newly introduced loss where the teacher survives, and every loss where the base survives. Record whether it is a last-hand state and whether the head's predicted clear probability or log-score is lower for its choice than for the available base action. Such disagreements are descriptive: a general preference for a lower immediate score can preserve resources, and recorded outcomes include stochastic realizations.

Keep equal state weight in aggregate errors and report exact sample sizes. This diagnostic reports descriptive counts and means, without a new significance or advancement gate. Existing prediction-metric arithmetic is already tested. The new analysis checks its all-state proposal metrics against the prediction audits with fixed absolute/relative tolerances of 1e-5, declared before execution. The full-support forward and original proposal-batch forward already passed their overlap check but can differ numerically; report the actual aggregate differences. Base/selected counts and sets must match the retention audits exactly. This analysis does not claim a second independent implementation of all new statistics.

Save one derived row per eligible state plus bounded fatal-case details, both-arm summaries and source pins. Allow 600 seconds plus 30 seconds of supervision grace. Use the result to decide whether to investigate support coverage, preference overfitting or preservation of the base preference pathway before another fit. Earlier saved checkpoints remain available, but their retention is unmeasured and requires a separately declared evaluation. No world-model work or confirmation fit is introduced here.
