# Controlled survival-ranking objective for the relational consequence scorer

The [training inventory](consequence_survival_pair_inventory_results_20260928.md) finds that 270 of 320 original-proposal preference errors compare non-teacher survivors with fatal actions. Test whether direct supervision of these relations improves action selection. This changes the preference objective only, using the existing relational model and admitted labels. It does not establish that representation or objective alignment is the sole bottleneck.

Retain the complete legal-action teacher cross-entropy, score MSE and clear BCE with their existing unit coefficients. Add `4 × mean_pairs softplus(preference(fatal) − preference(survivor))` at last-hand states containing observed surviving and fatal labelled alternatives. Average pairs within each state, then divide by the original optimizer batch's state count; inactive states contribute zero. Coefficient 4 reuses the earlier ranking study's fixed scale without a sweep. Use all 3,396 admitted pairs at 430 states, including 1,030 pairs involving expanded labels. Do not oversample, weight states differently elsewhere, infer missing outcomes, or treat score differences alone as preferences.

Survival is the recorded not-GAME_OVER outcome, including native survival effects. These are original-RNG observations, not deterministic or conditional-probability labels. The mask and outcomes are training targets only. The model still receives only frozen visible features; no seed, hidden RNG, target-derived feature or simulator state enters its inputs. Selection remains complete legal-play preference argmax, with lowest-ID ties and existing base non-play preservation.

Use the identical 132,035-parameter relational architecture, original seed-0 initialization, frozen features, 292,762 labels on 47,149 states, original score normalization, training order and optimizer recipe as the relational coverage control. Keep CPU FP32, one thread, AdamW .001 with betas .9/.999, epsilon 1e−8, zero weight decay, clipping at 1, batch128, 20 epochs, 7,380 updates and 942,980 state presentations. Save epochs0/5/10/20 and use fixed20. This gives 67,920 pair presentations and 8,600 active-state presentations, alongside unchanged consequence and legal-action exposures. Run one exploratory fit only; final independent confirmation remains reserved for a qualifying candidate.

Before fitting, test analytic pair losses and gradients, zero-coefficient equivalence, padding rejection, state-balanced normalization and complete-state microbatch equivalence. Validate output gradients against an independent float64 reference. At native preflight, reuse the first three fixed control batches without optimizer steps; batch0 has no active pairs and batch1 has five pairs at one state. Capture both batches, reconcile zero-pair gradients with the saved control batch, and verify nonzero added loss/gradients on batch1. Map every inventory pair to the unchanged seven-slot labels and complete legal support. Preserve all initial model tensors. Use the existing runtime projection and fixed-budget rule before admitting a fit.

Compare the fixed endpoint with the relational coverage control using the same prediction and retention gates, original-proposal curves, every legal development action and complete chosen-action outcome assessment. Also hold the control's 6,008 chosen actions fixed for paired consequence comparisons. Report training survival-ranking changes as mechanism evidence, not a success substitute. No duration choice, feature branch, base-logit prior, confidence gate or data-diversity change is combined with this experiment.

Advancement still requires all existing prediction and retention gates, followed by the unchanged fresh sampled-win, greedy-retention, early-attribution and final independent-fit confirmation requirements. A local survival gain alone does not meet the long-horizon objective. World models remain deferred.
