# Isolate action-relative terminal learning

**Question.** Does fitting shared state outcomes interfere with learning transferable terminal action differences in the frozen RMS features? The [saved decomposition](consequence_terminal_information_results_20260928.md) finds a state-mean gradient about 25 times the action-relative gradient at initialization, plus validation error in action differences themselves. Features vary comparably across splits, and coarse comparison shapes are represented. Strong alternatives remain sparse consequential contexts, stochastic labels and readout limits. Gradient cancellation alone is not proof of harmful interference.

**One intervention.** Replace the RMS readout's joint terminal BCE with conditional terminal-label likelihood given the observed number of winning branches. Keep the same frozen RMS features and 800/200 source-game split, coefficient penalty 0.001, Newton recipe and numerical budget. With one winning branch, use softmax scores to identify it; with two winning branches, use negative scores to identify the losing branch. States with zero or three wins contribute exactly zero conditional loss, not new invented preferences. Divide the sum of conditional losses by `3 * 800`, preserving its initialization gradient equal to the preceding BCE's action-relative component. Do not rescale by the number of mixed states or sweep a loss coefficient.

Use one 384-parameter linear score and a fixed zero intercept; a free intercept is unidentifiable under this likelihood. Center features within each three-action training group only for stable arithmetic: common score shifts cancel exactly. Inference is simply the linear score on the RMS feature and never receives terminal counts, outcomes, seed or teacher action identity. Train one exploratory endpoint from zero weights; max100 Newton updates, gradient∞≤1e-8, Armijo1e-4 with at most30 halvings, float64 CPU. No calibrated absolute terminal-win probabilities are claimed.

**Prediction and spending rule.** If shared outcome fitting is the main issue, relative validation prediction should improve as well as training fit. If only training improves, objective separation alone is insufficient. Report conditional NLL on mixed states against uniform log(3) and the previous RMS predictor, pair ordering against base and RMS, same-clear ordering, and restricted-choice wins overall/early/later. Preserve 10,000 whole-game bootstrap intervals. Only consider a separately specified held-out source-game contrast collection if: training conditional NLL improves on the previous RMS readout; validation conditional NLL beats both uniform and RMS; validation pair ordering beats base and retains RMS; early pair ordering retains base; same-clear ordering exceeds50%; and restricted choices retain base wins overall and early. These are point-estimate spending criteria for this relative target, not replacements for earlier failed absolute-prediction gates or policy readiness. A pass would still require source-game holdout, every actual selected alternative assessed, retention and all original fresh-game/greedy/early-attribution/final-confirmation evidence.

The conditional target is a relative-label model, not proof of known expected action values or independent branch outcomes. It uses the same original-RNG common-controller labels. All 1,000 source games contributed to the feature fit and the validation split is exposed. Comparisons to base action scores are diagnostic; their scale was not trained for terminal-label likelihood. No existing rejected candidate is revived, and no policy coefficient or threshold is selected.

**Budget.** Reuse the saved arrays; one fit and independent numerical audit, maximum600 seconds per phase plus30 supervisor grace, expected under a few seconds. Independently verify conditional likelihood by subset enumeration, derivatives, common-shift invariance, initialization-gradient equivalence, recorded updates, stationarity, exact data/control identities and all metrics. Audit is not another fit. If the fixed criteria fail, stop this recipe without a sweep or confirmation fit and use the result to choose the next mechanism to investigate.
