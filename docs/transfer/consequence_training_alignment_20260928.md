The matched relational readout improves held-out consequence prediction but fails clear retention. Its [saved residual diagnosis](consequence_relational_coverage_residual_results_20260928.md) shows both consequence errors and preferences that contradict predicted consequences. Before another fit, measure whether comparable errors already occur on supervised training alternatives, especially last-hand decisions.

Use only the saved epoch-20 predictions for the pooled and relational coverage fits on their original 245,637 training proposals across 47,149 states. Both models trained on these proposals plus 47,125 expanded labels; saved six-slot curves do not cover the added actions. No new inference is needed. Do not describe a teacher-containing restricted argmax as the actual full-action policy, or use it for deployment.

Freeze both admitted prediction owners/audits, the shared original training labels, exact prediction arrays, metric helper and this plan. Reproduce the existing original-training proposal MSE/BCE/Brier and within-proposal teacher NLL for each model before reporting new summaries. Validate array format, complete row count, finite values, unique actions, teacher placement, game identities and proposal counts. Read float32 NPY arrays with a bounded standard-library parser, without importing native/model/engine packages.

For all states, last-hand states and states with more hands remaining, report proposal metrics, teacher agreement within proposals, restricted-argmax and base outcomes where base is a play, gained/lost clears, and selected-versus-base consequence disagreement on lost clears and fatal overrides. Report the last-hand count where the teacher fails but an assessed alternative survives; these are realized label conflicts, not proof of an incorrect conditional policy.

On last-hand states containing both surviving and fatal assessed actions, enumerate every survivor–fatal pair. For score, clear and preference heads, count correctly ranked, tied and incorrectly ranked pairs and average the error fraction equally across eligible states. Break these summaries down by whether the teacher survives. This is a ranking diagnostic over assessed training alternatives, not an optimized selector. Preserve original-RNG labels; do not reinterpret them as conditional probabilities or deterministic targets.

Save per-state derived rows and aggregate results. Check that mutually exclusive group counts, ranking-pair totals and outcome transitions reconcile. This post-hoc audit uses a 600-second budget plus 30-second supervision grace, takes no optimizer steps, selects no checkpoint or confidence threshold, and requires actual owner exit before admission. Reuse tested metric routines; reconciliation is not a second independent implementation of every new statistic. No architecture or objective change follows automatically from this result.
