# Training-action coverage before expanding consequence labels

The [residual diagnosis](consequence_full_support_residual_results_20260928.md) finds much larger consequence errors on selected actions outside the original per-state proposals. Measure the existing training coverage before spending on labels or another fit.

Use the single full-support pooled model's originally fixed **epoch 20**, not a checkpoint selected by development outcomes. Score all 12,249,244 legal plays at the 47,149 teacher-play states from the original 1,000 training games (seeds 4000000–4000999). Reuse the admitted frozen feature cache, complete legal support, original labels, score normalization and saved proposal predictions. No development or confirmation inputs enter this measurement.

For every state, record the highest-preference legal play, with lowest global action ID breaking exact ties. Separately identify **the highest-preference legal play outside that state's original proposals**, if any. This fixes a concrete one-additional-action candidate without a confidence threshold. Include all teacher-play training states in the coverage analysis, including those where base would choose a non-play. Also report the actual play-only correction rule's eligibility, preserving base non-play actions, so these denominators cannot be confused.

This study does not yet generate new labels or authorize a fit recipe. It measures how often the existing full-support choice lacks an original consequence label, how many additional labels the fixed candidate rule would require, and the candidate's full-support rank. Report all, early/later, eligible/ineligible, base matches/differs from teacher and last-hand groups. Do not infer outcomes for actions whose labels are absent.

Export CPU FP32 predictions for all legal actions in the existing packed support order. Keep the model in eval mode without gradients or optimizer steps; install the frozen runtime before project/native imports. Verify each original proposal's predictions against the admitted epoch-20 training array within rtol/atol 1e-5. Preserve card order through selected/retained slot lists. Inputs are only the existing visible features and action membership; no simulator state, seed or hidden RNG enters the scorer.

A separate saved-data audit must verify every original legal mask, support offset, state identity, proposal overlap, argmax, outside-proposal candidate, selected/retained slots, NLL/rank arithmetic and summary. It must reproduce the original training proposal metrics and the coverage worker's counts. It performs no second neural forward. Bound measurement and audit to 900 seconds each plus 30 seconds supervision grace. Admit only after actual phase and owner exits. Preserve the original fit failure and successful saved-artifact recovery provenance.

If a later additional-label experiment proceeds, use training-only candidates and original-RNG continuations, retain the original labels, and hold architecture, features, full-support preference loss, target normalization and state exposure fixed. Specify equal-state consequence weighting explicitly before fitting. That later experiment still receives only one exploratory fit and must pass prediction and retention before autonomous evaluation; the final independent confirmation and long-horizon win-rate bar is unchanged.
