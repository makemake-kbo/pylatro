# Conditional CPU evaluation-interface check

Execute only after the single family fit and its complete development scan have successful whole-owner exits and all original 13 development checks pass. This preparation does not select another policy or start autonomous games.

Load the admitted candidate, the admitted conditional parent, and the previously verified zero-family checkpoint through their strict loaders on CPU. Keep the frozen source, float32 policy, temperature one and mixture 0.5. Use the first 128 original training rows, first and last active training batches, and one fixed mixed batch containing the first 16 pre-Ante-four and first 16 Ante-four-or-later training rows. No teacher label selects a row; labels are used only to verify likelihood equality.

The zero-family adapter and disabled new head must reproduce the conditional parent, including raw policy tensors, critic values, legal teacher likelihoods and joint modes. The candidate adapter must reproduce direct extended inference and reconstruction from its raw outputs. Verify that inference does not consume RNG; under a temporary fixed CPU RNG state, direct and adapted sampling must return the same actions and leave the same RNG state.

Use the existing permanent first-passage routing component with the zero-family adapter and candidate adapter on the fixed mixed batch. Its raw outputs and critic values must equal independent row selection before one sampled distribution. Check matching sampled actions and RNG consumption. This verifies the interface and one mixed batch; it does not replace the existing full-game routing/control reproduction or establish early-policy benefit.

Use one pause-aware owner with 600 active seconds plus thirty seconds of owner grace. No optimizer step, game simulation, coefficient change or native-model job in parallel. Require actual successful whole-owner exit and unchanged checkpoint/model hashes before admitting the interface check. A qualified candidate still requires a separately specified game-evaluation protocol and the original final proof bar.
