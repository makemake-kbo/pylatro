# Dense replacement supervision on the original fixed corpus

Collect native teacher comparison targets for all 57,257 active SHOP states in the original 1,000 training games and all 7,512 active states in the existing 128-game development panel. These are the same games underlying the earlier ordinary and auxiliary comparisons. Retain all game outcomes, all selected non-sale states, and games with no selected states in factual replay and auditing. Do not add the 4,000-game diversity extension to this collection. Holding the original population fixed supports a subsequent supervision comparison rather than confounding new labels with new games. The full long-horizon objective and its existing qualification requirements remain unchanged.

Selection is the previously admitted, observation-only predicate: SHOP, exhausted Joker capacity, at least one visible offered Joker, and at least one legal owned-Joker sale. Use the census's pinned indices and original fourteen-field caches. Replay every one of the 228,186 factual decisions and require exact field equality, legal recorded actions, and original game endpoints. Query the teacher only at selected states. No proposed, counterfactual, or model action is executed.

Use the verified complete-pair observer and the unchanged native source. A fresh teacher with empty score/sample caches receives each copied factual state and mask. Preserve native caching within that one query and its eviction rule. The pilot found only a modest time saving from cross-query reuse; independent annotation targets are preferred for this collection. Reproduce every cached teacher action. On each game's first and last distinct selected index, additionally query a fresh teacher with empty caches and the original comparison observer. Require exact action, last-decision, candidate-list, and summary equality. All 245 archived full-flow controls from the first four training games must reproduce exactly, including state/input hashes, IDs, events, and pair statuses. Every query must preserve the factual runner fingerprint, observation, global card-ID allocator, and Python/NumPy/Torch CPU random state.

Record all native comparison candidates, every pair iteration and filter outcome, and an exhaustive status for every readout-supported pair. Proposed pair support does not imply current affordability or a legal combined sale/purchase action. Keep numeric labels only where the native source computes them:

- Forecast score and forecast utility, including baseline and proposed-portfolio values, for scored pairs even when an immediate-score filter rejects them.
- Native net gain, income and price components only for pairs that reach final comparison.
- Explicit filter or preemption status for every potential pair. Unassessed gains remain absent, never zero or synthetic negative labels.

The intended learning question is whether this dense comparison signal improves representation of replacement advantage and the decision to sell beyond chosen-action supervision. This collection freezes the annotation population and target semantics; it performs no fit and does not select loss weights, model width, training duration, or a policy using development results. The subsequent single exploratory fit needs its own controlled recipe, retained ordinary controls, all thirteen existing spending checks, and eventual fresh-game/early-attribution validation. Only the final adopted intervention receives an independent confirmation fit.

Use only current observable policy inputs for any later learner. Card IDs, seeds, native state hashes, hidden RNG, and game endpoints are audit metadata. Teacher forecast values are noisy heuristic targets with demonstrated card-ID sampling sensitivity; they are not expected win values or guaranteed functions of the complete encoded observation. No sampler, teacher, input schema, existing label, or checkpoint is changed.

Run training then development sequentially under one pause-aware owner, with a separate native worker for each split. Save an exclusive per-game JSONL plus a completion record containing the factual observation-chain hash and original endpoint. Partial files and completed prefixes remain unadmitted until both workers, the whole owner, and the independent auditor exit successfully. Preserve failures; use a new version and an explicit prefix-adoption audit if recovery is necessary. Do not inspect partial scientific outcomes or choose targets using them.

Freeze each worker's active-time budget as `ceil(2 * (pilot_prior_fresh_query_seconds / 245 * (selected_states + fresh_controls) + pilot_nonquery_seconds / 889 * factual_decisions) + 180)`. Here the pilot is the admitted full-flow check; `pilot_nonquery_seconds` is its elapsed time minus cached-query time. Add 30 owner seconds per worker. The doubled estimate is a bound, not a runtime promise; explicit user pauses suspend its clock. Check live work about ten minutes apart. No live agent delegation or concurrent native workload.

An independent saved-data auditor must rehash sources and caches, reproduce selection, every factual observation-chain hash and selected input hash, row identities/actions, game endpoints, and counts. It must reconstruct pair support, native filter predicates, final gain and price arithmetic, strict candidate selection, all fresh controls and all archived pilot traces. Raw game records must be streamed rather than retained collectively in memory. Actual whole-owner success is mandatory before invoking admission; no training or game qualification follows from collection success alone.
