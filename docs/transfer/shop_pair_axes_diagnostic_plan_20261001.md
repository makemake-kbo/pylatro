# Separate owned-card discrimination from offer discrimination

The relative-consequence experiment improves development aggregate pair concordance by 0.81 percentage points, yet its conditional owned-card agreement is 29.73%, versus 31.58% for the absolute-gain control. Training owned-card agreement stays near 30%. Before another fit, determine which comparisons account for the small aggregate improvement.

Use only the admitted relative and absolute-gain predictions and their identical recorded continuous-gain labels. Partition unordered comparisons between observed replacement pairs into three exhaustive, disjoint types: the same offer and different owned slots; the same owned slot and different offers; or different owned slots and different offers. The first type directly tests discrimination between removals while holding the proposed purchase fixed. Analyze all gain-labelled active states and, separately, teacher-sale states. These populations and all metrics are fixed before running the new diagnostic.

Within each type, report equal-decision sign concordance on unequal true gains, half credit for prediction ties, prediction-tie frequency, half squared contrast error, target contrast energy, and predicted contrast energy. Unknown gains remain excluded. Also report counts and fractions of observed comparisons. For each gain-labelled state with n pairs, a type's contribution to centered MSE is the sum of its squared difference errors divided by n squared. These contributions exactly add to the original centered MSE, including zero contributions for singleton states. Apply the same decomposition to the constant predictor's error. This identifies where error reduction occurs without changing the original metric's denominator.

Reconstruct the previously admitted overall concordance and centered errors. An independent scalar enumeration must reproduce every new per-state metric and pair count. Check empty/singleton support, missing entries, exact ties, additive owned-only and offer-only examples, permutation invariance and common-offset invariance on synthetic fixtures before the real analysis. All new code and the plan are pinned before outcomes.

Training uses all 1,000 games for points; development intervals use the existing tested aggregator with 10,000 paired resamples of all 128 complete games and seed 1729. Report candidate, control and paired differences with the actual eligible-decision counts. These are descriptive marginal intervals on an exposed panel. The independent scalar enumeration validates the inputs to those intervals; it does not independently reimplement the already tested bootstrap.

This is an oracle-supported diagnosis of recorded heuristic utility, not a deployable policy or eventual win value. No model forwards, simulator calls, new training, threshold selection, alternative pooling, or qualification changes. The rejected relative endpoint stays rejected. Neither weak within-offer discrimination nor improvement limited to other comparisons would uniquely identify capacity, representation, optimization or label noise as the cause. The result determines which of those hypotheses deserves a subsequent controlled investigation.
